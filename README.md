# Система обмена валют для онлайн-банка

**Десктопное приложение для автоматизации обмена валют с расчётом комиссии, контролем лимитов и ролевой моделью «пользователь / администратор».**

## 💱 Возможности приложения

- Загрузка актуальных курсов валют из внешнего API
- Автоматический расчёт комиссии 2% для всех обменов
- Спецусловия для крупных платежей (сниженная комиссия от определённой суммы)
- Контроль лимитов обмена на одного пользователя
- Ролевая модель с разделением прав (пользователь / администратор)
- История операций с сохранением в файл
- Администрирование: управление лимитами, комиссиями, блокировка пользователей

## 📋 Функциональные требования

- ✅ Выбор нужного направления обмена
- ✅ Ввод пользователем валюты для обмена
- ✅ Вывод требований к обмену
- ✅ Вывод истории операций
- ✅ Сохранение истории в файл
- ✅ Автоматическая загрузка курсов валют из внешнего API
- ✅ Автоматическое добавление комиссии 2%

## 👥 Ролевая модель

| Роль | Действия |
|------|----------|
| **Пользователь** | Просмотр курсов, выбор направления обмена, ввод суммы, просмотр истории, сохранение истории в файл |
| **Администратор** | Просмотр статистики, настройка лимитов и спецкомиссий, блокировка/удаление пользователей |

## 🖥 Технологии

- **Язык:** C#
- **Фреймворк:** .NET (Windows Forms)
- **Среда разработки:** Visual Studio 2022 Community
- **Хранение данных:** JSON / XML / SQLite
- **API:** внешний REST API (курсы валют)
